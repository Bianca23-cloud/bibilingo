Installer Bibilingo

🤖 Android – application complète, hors ligne

⬇️ Télécharger l'application Android (.apk)
  1. Touchez le bouton, puis ouvrez le fichier téléchargé.
  2. Si Android le demande : Paramètres → Autoriser cette source, puis revenez.
  3. Touchez Installer, puis Ouvrir.
  4. Avec internet, une seule fois : Aide → Télécharger toutes les langues.

🪟 Windows 11 – en 1 clic

  1. Ouvrez cette page avec Microsoft Edge ou Google Chrome.
  2. Cliquez sur Installer Bibilingo (ou l'icône ⊕ « Installer » à droite de la barre d'adresse).
  3. Bibilingo apparaît dans le menu Démarrer.
▶️ Ouvrir Bibilingo dans le navigateur

🍏 iPhone / iPad

  1. Ouvrez cette page avec Safari.
  2. Touchez Partager (carré avec flèche ↑).
  3. Touchez Sur l'écran d'accueil → Ajouter.

Sur iPhone, la traduction d'une phrase nouvelle demande internet (règles d'Apple). Les favoris et les 30 phrases métier marchent hors ligne.
