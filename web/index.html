      Aide et confidentialité

      Comment ça marche ?

      1. Choisissez Română ou Français.
      2. Choisissez la langue d'arrivée.
      3. Appuyez sur 🎙️ et parlez : la traduction s'affiche et se lit toute seule. (Ou écrivez, puis ✨ Traduire.)
      4. Réécoutez (🔊), lentement (🐢), ou touchez un mot pour l'entendre seul.

      Ce qui marche sans internet

      • Partout : vos favoris, les 30 phrases métier (× 15 langues), l'historique, et l'audio si la voix de la langue est installée.
      • Sur PC Windows 11 avec Chrome ou Edge récents : la traduction de n'importe quelle phrase, sur l'appareil (le modèle se télécharge une fois).
      • Micro : sur l'appareil quand c'est possible ; sinon le navigateur utilise son service en ligne (Google ou Apple). L'état est affiché sous le micro.

      Langues hors ligne (application Android)

      À faire une fois, avec internet : environ 30 Mo par langue.

      Réglages

      En ligne, le texte est envoyé au service MyMemory (Translated, Italie). Désactivé par défaut. À ne pas utiliser pour une information confidentielle.

      Installer les voix (prononciation hors ligne)

      • Windows 11 : Paramètres → Heure et langue → Voix → Ajouter des voix (ex. « English (United Kingdom) »).
      • Android : Paramètres → Système → Langues → Synthèse vocale → Moteur Google → Installer les données vocales.
      • iPhone : Réglages → Accessibilité → Contenu énoncé → Voix → choisir la langue → télécharger.

      État de cet appareil

        Confidentialité (RGPD)

        Traduction hors ligne de l'application Android : Google ML Kit (modèles Google Traduction). Les traductions automatiques peuvent contenir des erreurs : vérifiez les phrases importantes.

        Bibilingo ne collecte aucune donnée, n'a pas de serveur, pas de publicité ni de traceur. Détails : politique de confidentialité.
